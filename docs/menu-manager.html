MenuManager

Core component for managing hierarchical menu structures

Overview

The MenuManager is responsible for managing the entire menu structure of your application. It supports hierarchical menu items, filtering based on user roles, and provides methods to add, remove, and retrieve menu items.

Class: MenuItem

Represents a single menu item in the hierarchy.

Properties
Property Type Description
id str Unique identifier for the menu item
label str Display label for the menu item
url str URL path for the menu item
icon Optional[str] Icon name (Bootstrap Icons)
parent_id Optional[str] ID of parent menu item
order int Display order (lower values appear first)
visible bool Whether the item is visible
required_roles List[str] Roles required to see this item
children List[MenuItem] Child menu items

Class: MenuManager

Methods
add_item(item: MenuItem)

Add a menu item to the manager

menu = MenuManager()
home = MenuItem(id='home', label='Home', url='/')
menu.add_item(home)
remove_item(item_id: str)

Remove a menu item by ID

menu.remove_item('home')
get_item(item_id: str) → Optional[MenuItem]

Get a menu item by ID

item = menu.get_item('home')
get_menu(user_roles: List[str] = None) → List[MenuItem]

Get filtered menu based on user roles

# Get public menu
public_menu = menu.get_menu([])

# Get admin menu
admin_menu = menu.get_menu(['admin'])
to_dict(user_roles: List[str] = None) → List[Dict]

Convert menu to dictionary format

menu_dict = menu.to_dict(['admin'])

Examples

Creating a Hierarchical Menu
from app.navigation.menu import MenuItem, MenuManager

menu = MenuManager()

# Create root items
home = MenuItem(id='home', label='Home', url='/', order=1)
dashboard = MenuItem(id='dashboard', label='Dashboard', url='/dashboard', 
                     required_roles=['admin'], order=2)

menu.add_item(home)
menu.add_item(dashboard)

# Create child items
users = MenuItem(id='users', label='Users', url='/dashboard/users',
                 parent_id='dashboard', required_roles=['admin'])
settings = MenuItem(id='settings', label='Settings', url='/dashboard/settings',
                    parent_id='dashboard', required_roles=['admin'])

menu.add_item(users)
menu.add_item(settings)

# Get menu for admin user
admin_menu = menu.get_menu(['admin'])
