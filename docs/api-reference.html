API Reference

Complete API documentation for Jato

Core Classes

MenuItem

Represents a single menu item

Properties:
  • id: str - Unique identifier
  • label: str - Display label
  • url: str - URL path
  • icon: Optional[str] - Icon name
  • parent_id: Optional[str] - Parent menu item ID
  • order: int - Display order
  • visible: bool - Visibility flag
  • required_roles: List[str] - Required user roles
  • children: List[MenuItem] - Child items
MenuManager

Manages menu structure

Methods:
  • add_item(item: MenuItem) → None
  • remove_item(item_id: str) → None
  • get_item(item_id: str) → Optional[MenuItem]
  • get_menu(user_roles: List[str]) → List[MenuItem]
  • to_dict(user_roles: List[str]) → List[Dict]
NavigationRouter

Handles routing and navigation

Methods:
  • register_route(path, name, menu_item_id, required_roles, metadata) → None
  • get_route(path: str) → Optional[Dict]
  • get_breadcrumb(path: str) → List[Dict]
  • get_active_menu_item(path: str) → Optional[str]
PermissionManager

Manages roles and permissions

Methods:
  • create_role(role_name: str, permissions: Set[str]) → None
  • add_permission(role_name: str, permission: str) → None
  • has_permission(role_name: str, permission: str) → bool
  • has_any_role(user_roles: List[str], required_roles: List[str]) → bool
