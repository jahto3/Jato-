NavigationRouter

Manages routing and navigation with breadcrumb support

Overview

The NavigationRouter handles route registration, breadcrumb generation, and active menu item tracking. It works in conjunction with the MenuManager to provide a complete navigation solution.

Methods

register_route(path, name, menu_item_id, required_roles, metadata)

Register a route with navigation metadata

from app.navigation import get_navigation

navigation = get_navigation()
navigation.register_route(
    path='/dashboard',
    name='dashboard',
    menu_item_id='dashboard',
    required_roles=['admin']
)
get_route(path) → Optional[Dict]

Retrieve route information by path

route = navigation.get_route('/dashboard')
get_breadcrumb(path) → List[Dict]

Get breadcrumb navigation for a path

breadcrumb = navigation.get_breadcrumb('/dashboard/users')
# Returns: [
#     {'label': 'Home', 'url': '/', 'active': False},
#     {'label': 'Dashboard', 'url': '/dashboard', 'active': False},
#     {'label': 'Users', 'url': '/dashboard/users', 'active': True}
# ]
get_active_menu_item(path) → Optional[str]

Get the active menu item ID for the current path

active_id = navigation.get_active_menu_item('/dashboard')
# Returns: 'dashboard'

Usage Example

from flask import render_template, request
from app.navigation import get_navigation

@app.route('/dashboard')
def dashboard():
    navigation = get_navigation()
    
    # Get breadcrumb for current page
    breadcrumb = navigation.get_breadcrumb(request.path)
    
    # Get active menu item
    active_item = navigation.get_active_menu_item(request.path)
    
    return render_template('dashboard.html',
                         breadcrumb=breadcrumb,
                         active_item=active_item)
