PermissionManager

Role-based access control management

Overview

The PermissionManager handles user roles and permissions. It allows you to define roles, assign permissions to roles, and check user permissions and roles.

Methods

create_role(role_name, permissions)

Create a new role with optional permissions

from app.navigation import get_permission_manager

perm_mgr = get_permission_manager()
perm_mgr.create_role('admin', {'read', 'write', 'delete'})
perm_mgr.create_role('editor', {'read', 'write'})
perm_mgr.create_role('viewer', {'read'})
add_permission(role_name, permission)

Add a permission to a role

perm_mgr.add_permission('editor', 'publish')
has_permission(role_name, permission) → bool

Check if a role has a specific permission

if perm_mgr.has_permission('admin', 'delete'):
    # Allow deletion
    pass
has_any_role(user_roles, required_roles) → bool

Check if user has any of the required roles

user_roles = ['editor']
required = ['admin', 'editor']

if perm_mgr.has_any_role(user_roles, required):
    # User has permission
    pass
