Simple to Use

Get started in minutes with intuitive Python API

Create Menu Items
from app.navigation.menu import MenuItem, MenuManager

# Create manager
menu = MenuManager()

# Add menu item
home = MenuItem(
    id='home',
    label='Home',
    url='/',
    icon='house',
    order=1
)
menu.add_item(home)

# Add admin-only item
dashboard = MenuItem(
    id='dashboard',
    label='Dashboard',
    url='/dashboard',
    required_roles=['admin']
)
menu.add_item(dashboard)
Register Routes
from app.navigation import get_navigation

# Get navigation router
navigation = get_navigation()

# Register routes
navigation.register_route(
    '/dashboard',
    'dashboard',
    menu_item_id='dashboard',
    required_roles=['admin']
)

# Get breadcrumb for current path
breadcrumb = navigation.get_breadcrumb('/dashboard')

# Get active menu item
active = navigation.get_active_menu_item('/dashboard')

Installation

Get up and running in three simple steps

1 Clone the Repository 
git clone https://github.com/jahto3/Jato-.git
cd Jato-
2 Install Dependencies 
pip install -r requirements.txt
3 Run the Application 
python main.py

Visit http://localhost:5000 in your browser
